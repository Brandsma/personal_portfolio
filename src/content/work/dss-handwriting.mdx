This project is an end to end handwriting analysis pipeline for Dead Sea Scroll images. It takes binarized manuscript images, breaks them into lines and characters, recognizes each character, classifies writing style, and writes per-pageoutput files with transcribed text plus a style label.

Technically, the pipeline combines several tools and models. Line segmentation uses a MATLAB implementation of multi-skew line extraction with anisotropic Gaussian filtering. Character segmentation then runs in Python with confidence-basedwindow scanning over each line image. Character recognition is handled by a TensorFlow CNN trained for 27 Hebrew character classes, with preprocessing that cleans noise, trims whitespace, and normalizes character crops to 32x32. Style classification is a separate stage that compares each recognized character image against style templates using distance metrics like Manhattan and Euclidean distance, then assigns a page-level style by majority vote across characters. The current style set in the data is Archaic, Hasmonean, and Herodian.

The interesting part is how the project deals with limited historical data. It includes custom augmentation work, including elastic morphing and a font interpolation workflow using SVG path morphing to generate synthetic glyph variants between reference shapes and observed handwriting forms. The main challenges are practical engineering ones: long runtime in segmentation, dependency compatibility between Python, TensorFlow, Tesseract, and MATLAB Engine, strict input assumptions such as binarized JPGs and relative path layout, and handling ancient Hebrew output where a full Unicode mapping is not always straightforward so a custom character map is used.
